# Simple Password Manager 

This is a beginner-friendly password manager project created using Python.  
It helps users securely store their passwords locally.

---

## Features
- Add new passwords
- View saved passwords
- Update existing passwords
- Delete passwords
- Simple command-line interface

---

## Technologies Used
- Python 3
- File Handling (for saving passwords)
- Basic Encryption (optional - if you want to add later)
